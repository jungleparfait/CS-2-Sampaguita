# Distance Calculator

## Description

This program calculates the distance between two points (x1, y1) and (x2, y2) on a Cartesian plane
using input values and a math library.

## How to Run

1. Open the program file in VS Code, Replit, or Google Colab.

2. Run the program.

3. Enter the values for x1, y1, x2, and y2.

4. Check the distance displayed on the screen.

## Input Needed

- x1

- y1

- x2

- y2

## Sample Output

Enter x1: 6

Enter y1: 7

Enter x2: 5

Enter y2: 5

The distance between the two points is: 1.0
